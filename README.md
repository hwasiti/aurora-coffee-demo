# Aurora Coffee Roasters — demo storefront

A **fictional** coffee-shop website used to test the embeddable support-chat
widget of [Customer Help AI](https://github.com/hwasiti/chatbot) on a real,
externally-hosted page (cross-origin embed test).

- `index.html` / `faq.html` — the storefront
- `widget.js` — self-hosted dev build of the Customer Help AI embed loader
- `kb/` — the "company documents" (PDF / TXT / CSV) ingested into the
  widget's RAG knowledge base

No real products, prices, addresses, or phone numbers. All email addresses
use the reserved `.example` TLD.
